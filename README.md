Healthcare Data Analysis & Visualization using Power BI

Project Overview

This project focuses on analyzing healthcare data to uncover meaningful insights into patient demographics, medical conditions, billing patterns, hospital admissions, and patient length of stay.

The analysis was conducted using Microsoft Excel and Power BI. The dataset was cleaned and transformed to prepare it for analysis, while Power BI was used to create an interactive dashboard for exploring key healthcare metrics and trends.

The project demonstrates practical skills in data cleaning, data transformation, exploratory analysis, DAX, data visualization, and business intelligence.

Objectives

The main objectives of this project are to:

* Analyze patient distribution by age group and gender.
* Identify the most common medical conditions.
* Examine billing amount trends.
* Evaluate patient length of stay.
* Analyze hospital admission patterns.
* Present key findings through interactive visualizations.

Business Questions

This project addresses the following questions:

1. How many patients are included in the dataset?
2. What is the average patient age?
3. Which medical conditions are most common?
4. How are patients distributed across different age groups?
5. What is the relationship between billing amount and length of stay?
6. What trends exist in hospital admissions?

Data Cleaning & Transformation

The following data preparation steps were performed:

* Cleaned and standardized text fields.
* Created age group categories.
* Calculated patient length of stay.
* Extracted admission month.
* Removed duplicate records.
* Handled missing values.
* Created calculated columns and measures using DAX.

Dashboard Features

The Power BI dashboard includes:

* Total Patients KPI
* Average Age KPI
* Billing Amount Analysis
* Medical Condition Distribution
* Age Group Analysis
* Length of Stay Analysis
* Hospital Admission Analysis
* Interactive Filters and Slicers

Key Insights

The dashboard provides an interactive view of patient demographics, medical conditions, billing patterns, length of stay, and hospital admissions. These insights demonstrate how healthcare data can be transformed into meaningful information through data analysis and visualization.
